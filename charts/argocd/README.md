# argocd

Thin umbrella chart around the upstream
[`argo-cd`](https://github.com/argoproj/argo-helm) chart, published
through this repo's Rancher Marketplace catalog (see the root
[README](../../README.md#rancher-marketplace)). It adds no templates
of its own - just a dependency pin and defaults under `values.yaml`'s
`argo-cd:` key.

## Installing from Rancher

1. Add this repo's catalog under **Apps & Marketplace → Repositories**
   if you haven't already (`https://perspikapps.github.io/vps/`).
2. **Apps & Marketplace → Charts**, pick **argocd**, review/edit the
   values (see `values.yaml`'s comments - in particular whether
   `server.service.type: LoadBalancer` and `server.extraArgs:
[--insecure]` suit your cluster, or whether you'd rather put an
   Ingress with real TLS in front of it instead), and install.
3. Once the `argocd-server` pod is up, the initial admin password is
   auto-generated by the chart into the `argocd-initial-admin-secret`
   Secret in the `argocd` namespace:

    ```sh
    kubectl -n argocd get secret argocd-initial-admin-secret \
        -o jsonpath='{.data.password}' | base64 -d
    ```

    That secret is deleted the first time you change the password.

## What's required

Nothing has to be filled in to install - every value has a workable
default. The one thing worth deciding up front is how you're exposing
the server (see step 2 above); the default `LoadBalancer` + plain-HTTP
setup mirrors what this repo's old bash-based install used on a
Tailscale-gated VPS and is not meant as a public-facing default.
